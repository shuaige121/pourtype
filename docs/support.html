Pourtype Support

macOS menu-bar utility

Questions, bugs and ideas: open an issue on GitHub.

Nothing happens when I press ⌘⇧V or ⌘⇧C

Another app may already use that shortcut; Pourtype says so in its Settings. You can always start both actions from the menu bar icon.

It asks for Accessibility or Screen Recording

Open System Settings → Privacy & Security, turn Pourtype on under Accessibility (for typing) and Screen Recording (for grabbing text). Pourtype's Settings window shows which ones are on.

The keyboard and mouse are held — how do I get them back?

Press Esc. Input is also returned when the text is finished, when another app comes to the front, or if the displays change.

It typed without the frosted veil

In password fields macOS turns on Secure Input, which hides the keyboard from every app, so it cannot be held. Pourtype then types without the veil; ⌃⌥⌘. stops it.

支持

问题、故障和建议：请在 GitHub 提 issue。

按 ⌘⇧V 或 ⌘⇧C 没反应

可能有别的 App 占用了这个快捷键，Pourtype 的设置里会显示出来。两个功能都可以从菜单栏图标启动。

提示需要辅助功能或屏幕录制权限

打开「系统设置 → 隐私与安全性」，在「辅助功能」（打字用）和「屏幕录制」（识字用）里打开 Pourtype。Pourtype 的设置窗口会显示哪些已经打开。

键盘鼠标被锁住了，怎么拿回来？

按 Esc。文字打完、别的 App 切到前台、或显示器有变化时，也会自动归还。

打字时没有出现磨砂遮罩

在密码框里 macOS 会开启「安全输入」，所有 App 都看不到键盘，因此无法锁定。这时 Pourtype 会直接输入，用 ⌃⌥⌘. 停止。
