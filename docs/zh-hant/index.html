三件事

⌘⇧V

代為打字

有些網站和對話框不讓你貼上。照常複製文字，點進輸入框，按下快速鍵，Pourtype 就會替你一個鍵一個鍵地打進去。換行以 Shift+Return 輸入，聊天框不會提早送出。

⌘⇧C

擷取文字

在螢幕任何位置拖曳一個框，即使文字在圖片裡也行。Pourtype 用 Apple 的 Vision 在本機辨識並複製。支援簡體中文、繁體中文、英文和日文。

歷史記錄

隨時找回

擷取過和輸入過的內容，都保存在你 Mac 上一份可搜尋的清單裡。可以再次複製，或再次輸入。隨時可以清除，保留期限也可選 7、30、90 或 365 天。

打字時，一切由你掌控

  • 螢幕會蓋上一層霧面遮罩，只留出正在輸入的視窗。鍵盤和滑鼠會被鎖定，焦點不會被移走。
  • 按 Esc 立即停止。如果有其他 App 切換到前景，輸入也會停止；按鍵只會送給目標 App。
  • 按住 ↑ 或 ↓ 調整速度，範圍是每秒 3 到 150 個字元；按住 ← 或 → 調整節奏，從平穩到隨機。
  • 一張卡片會顯示目標 App 與視窗、正在輸入的文字、進度和剩餘秒數。有多個螢幕時，其他螢幕會出現一張小卡片，指向目標螢幕。

怎麼用

代為打字

  1. 照常複製文字。
  2. 點進禁止貼上的輸入框，按下 ⌘⇧V。
  3. 看著卡片就好，想停就按 Esc。

擷取文字

  1. 按下 ⌘⇧C。
  2. 在文字上拖曳一個框，文字就複製到剪貼簿了。

常見問題

Mac 上輸入框禁止貼上，要怎麼把文字輸入進去？

複製文字，點進輸入框，按下 Command-Shift-V。Pourtype 會把剪貼簿文字當作真實按鍵敲進去，所以貼上被擋住的地方也能用。輸入時，螢幕會蓋上霧面遮罩，只留出正在輸入的視窗，按 Esc 即可立即停止。

Mac 上要怎麼複製圖片裡的文字？

按下 Command-Shift-C，在文字上拖曳一個框。Pourtype 用 Apple 的 Vision 在本機辨識文字，並複製到剪貼簿。支援簡體中文、繁體中文、英文和日文。

安全嗎？會把我的資料傳到哪裡嗎？

Pourtype 在本機執行，不發出任何網路請求，也不收集任何資料。文字辨識在你的 Mac 上完成，歷史記錄只保存在你的 Mac 上，隨時可以清除。原始碼公開在 GitHub 上。

打字途中要怎麼停下來？

按 Esc。輸入會立即停止，鍵盤和滑鼠隨即釋放。如果有其他 App 切換到前景，它也會自動停止。在密碼欄位中，請按 Control-Option-Command-句號。

支援中文、日文和韓文嗎？

支援。Pourtype 可以輸入中文、日文、韓文和表情符號。從螢幕擷取文字時，可辨識簡體中文、繁體中文、英文和日文。

可以在密碼欄位裡輸入嗎？

可以，但有一個限制。在密碼欄位中 macOS 會開啟 Secure Input，鍵盤無法被鎖定，Pourtype 會改為一般輸入。按 Control-Option-Command-句號可以停止。

可以調整打字速度嗎？

可以。按住 ↑ 或 ↓ 調整速度，範圍是每秒 3 到 150 個字元；按住 ← 或 → 調整節奏，從平穩到隨機。

可以更改快速鍵嗎？

可以。在設定中按一下快速鍵，再按下新的組合，需包含 Command、Control 或 Option 其中之一。預設是 Command-Shift-V 輸入剪貼簿，Command-Shift-C 擷取文字。

App 支援哪些語言？

介面有繁體中文、簡體中文、英文和日文，會跟隨 Mac 的系統語言。

要多少錢？在哪裡取得？

Pourtype 預計在 Mac App Store 上架，價格 2.99 美元，一次買斷，目前尚未上架。需要 macOS 14 或更新版本。原始碼在 GitHub 上，採用 PolyForm Noncommercial 1.0.0 授權：原始碼公開，個人與非商業使用免費，但不是開源軟體。

天生注重隱私

Pourtype 在本機執行，不發出任何網路請求，也不收集任何資料。

它需要「輔助使用」權限（用於輸入，以及在輸入時鎖定鍵盤和滑鼠）和「螢幕錄製」權限（用於辨識你框選範圍內的文字）。只有在輸入時才會鎖定你的操作。
