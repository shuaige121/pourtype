コピーした文字を、打ち込む。
見えている文字を、コピーする。

入力欄やダイアログによっては貼り付けが禁止されています。Pourtype は、クリップボードの文字を実際のキー入力として代わりに打ち込みます。画像の中の文字も、コピーできます。すべて Mac の中で完結します。

できること

⌘⇧V

クリップボードを入力

貼り付けを受け付けないサイトやダイアログがあります。いつも通りコピーして、入力欄をクリックし、ショートカットを押すだけ。Pourtype が 1 文字ずつ打ち込みます。改行は Shift+Return で入力するので、チャットが途中で送信されません。

⌘⇧C

画面の文字をコピー

画面上の好きな場所をドラッグして囲むだけ。画像の中の文字でも大丈夫です。Pourtype が Apple の Vision で Mac 上で認識し、コピーします。簡体字中国語、繁体字中国語、英語、日本語を読み取れます。

履歴

あとで探せる

コピーした文字も入力した文字も、Mac 内の検索できる一覧に残ります。もう一度コピーも、もう一度入力もできます。いつでも消去でき、保存期間は 7・30・90・365 日から選べます。

入力中も、操作はあなたの手の中

  • 入力中は画面にすりガラス状のベールがかかり、入力先のウインドウだけが見えます。キーボードとマウスは固定され、フォーカスは動きません。
  • Esc キーですぐに停止します。別の App が前面に来たときも停止し、キー入力は入力先の App にだけ届きます。
  • ↑ または ↓ を押し続けると速度を変更できます（毎秒 3〜150 文字）。← または → を押し続けると、一定のリズムからランダムなリズムまで変えられます。
  • カードに、入力先の App とウインドウ、流れていく文字、進行状況、残り秒数が表示されます。複数のディスプレイでは、ほかのディスプレイに入力先を示す小さなカードが出ます。

使い方

クリップボードを入力

  1. いつも通り文字をコピーします。
  2. 貼り付け禁止の入力欄をクリックして、⌘⇧V を押します。
  3. カードを見ているだけで OK。止めたいときは Esc。

画面の文字をコピー

  1. ⌘⇧C を押します。
  2. 文字の上をドラッグして囲むと、クリップボードにコピーされます。

よくある質問

Mac で貼り付け禁止の入力欄に文字を入れるには？

文字をコピーして入力欄をクリックし、Command-Shift-V を押します。Pourtype がクリップボードの文字を実際のキー入力として打ち込むので、貼り付けが禁止されている場所でも使えます。入力中は入力先のウインドウ以外がすりガラス状になり、Esc キーですぐに止められます。

Mac で画像の中の文字をコピーするには？

Command-Shift-C を押して、文字の上をドラッグして囲みます。Pourtype が Apple の Vision で Mac 上で文字を認識し、クリップボードにコピーします。簡体字中国語、繁体字中国語、英語、日本語に対応しています。

安全ですか？データはどこかに送られますか？

Pourtype は Mac 上だけで動作し、ネットワーク通信は行わず、データも収集しません。文字認識は Mac 上で行われ、履歴は Mac の中だけに保存されて、いつでも消去できます。ソースコードは GitHub で公開しています。

入力中に止めるには？

Esc キーを押してください。入力はすぐに止まり、キーボードとマウスが解放されます。別の App が前面に来たときも自動で停止します。パスワード欄では Control-Option-Command-ピリオドを押します。

日本語・中国語・韓国語の文字も入力できますか？

はい。Pourtype は日本語・中国語・韓国語の文字と絵文字を入力できます。画面から文字をコピーするときは、簡体字中国語、繁体字中国語、英語、日本語を認識します。

パスワード欄にも入力できますか？

はい。ただし制限が一つあります。パスワード欄では macOS が Secure Input を有効にするため、キーボードを固定できず、Pourtype は通常の入力に切り替わります。Control-Option-Command-ピリオドで停止できます。

入力の速さは変えられますか？

はい。↑ または ↓ を押し続けると速度を毎秒 3〜150 文字の範囲で、← または → を押し続けるとリズムを一定からランダムまで変えられます。

いくらですか？どこで入手できますか？

Pourtype は Mac App Store で 2.99 米ドル（買い切り）での公開を予定しています。現時点ではまだ公開されていません。macOS 14 以降が必要です。ソースコードは PolyForm Noncommercial 1.0.0 ライセンスで GitHub に公開しています。ソース公開（source-available）で、個人・非営利利用は無料ですが、オープンソースではありません。

プライバシー重視の設計

Pourtype は Mac 上だけで動作します。ネットワーク通信は行わず、データも収集しません。

「アクセシビリティ」の権限（入力のため、また入力中にキーボードとマウスを固定するため）と、「画面収録」の権限（囲んだ範囲の文字を読み取るため）を必要とします。入力をロックするのは入力中だけです。
