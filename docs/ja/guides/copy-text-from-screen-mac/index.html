Macで画像・動画・画面の文字をコピーする方法

執筆：Leonard Chow（Pourtype 開発者） · 更新日 2026-10-06
開示：私は Pourtype の開発者です。このページでは無料の方法も含め、すべての方法を紹介します。

結論

写真やプレビューの画像内の文字は、macOSの「テキスト認識表示」で選択してコピーできます。それ以外の場所や画面全体の文字は、スクリーンショットとショートカットアプリで認識するか、画面を囲んでコピーするPourtype（⌘⇧C）が使えます。まず無料の標準機能を試すのがおすすめです。

画像の中の文字、選択できないPDF、再生中の動画の字幕など、「見えているのにコピーできない文字」をMacで取り出す方法をまとめました。標準機能と無料の方法を先に、できない場面も正直に書きます。

写真・プレビュー・クイックルック：テキスト認識表示

macOSには、画像内の文字を認識する「テキスト認識表示」（Live Text）があります。Appleの手順では、プレビューで画像を開き、ドラッグして文字を選択し、Controlキーを押したまま選択部分をクリックして「テキストをコピー」を選びます。選択できないときは、「ツール」メニューの「テキスト選択」を有効にします（プレビュー）。

「写真」アプリでも同様です。画像の文字にポインタを置き、Controlキーを押したままクリックして「テキストをコピー」を選ぶか、選択してCommand＋Cを押します（写真）。

PCデポの解説では、macOS 12 Montereyから使え、プレビューで開くか、ファイルを選んでスペースキー（クイックルック）で表示して使えるとされています（PCデポ）。

Appleは、テキスト認識表示は地域や言語によっては利用できないことがあると案内しています。画像の文字がきれいに読めるとは限りません。

一時停止した動画の文字

動画を止めた画面の文字が選べるかどうかは、アプリによって異なる可能性があります。今回確認できたAppleの日本語ページには、動画の一時停止中の文字認識について書かれたものがなかったため、このページでは対応アプリや条件を断定しません。

確実に取り出したいときは、動画を一時停止して、後述のスクリーンショットや、画面を囲んでコピーする方法を使ってください。

スクリーンショット＋ショートカットでOCR

画面の一部を撮って、その画像から文字を取り出すショートカットを作る方法が、日本語の解説でよく紹介されています。スクリーンショットの範囲指定は、shift・command・4を同時に押すと、ポインタが十字に変わります（Apple）。

Qiitaの解説では、ショートカットアプリで次のようにアクションをつないでいます（Qiita）。

  1. 「スクリーンショットを撮る」
  2. 必要なら「イメージを切り取り」で範囲を絞る
  3. 「イメージからテキストを抽出」
  4. 「結果を表示」

一度作れば何度でも使えますが、組み立てる手間があります。また、Apple公式のショートカット解説の目次からは、このアクションの説明ページは確認できませんでした。アクション名はOSのバージョンで変わることがあるので、ショートカットアプリで検索して確かめてください。

コピーできないPDF

PDFの文字が選択できない場合、多くは文字ではなく画像として入っています。この場合は、PDFをプレビューで開いて画像として扱う方法や、スクリーンショットを撮ってテキスト認識表示やショートカットで読み取る方法が考えられます。ただし、PDFごとの結果は今回確認していません。手元のファイルで先にお試しください。

画面のどこでも囲んでコピー：Pourtype（⌘⇧C）

PourtypeはMacのメニューバーに常駐するアプリ（macOS 14以降）で、作者はLeonard Chowです。⌘⇧Cを押して画面の好きな範囲をドラッグで囲むと、中の文字をMac上でAppleのVisionで認識して、そのままコピーします。

  • 認識できる言語は、簡体字中国語、繁体字中国語、英語、日本語です。
  • 取り込んだ文字と、入力した文字の履歴は、Mac内に保存されて検索できます。履歴は消去できます。
  • ショートカットは設定で変更できます。アプリの表示言語は英語・簡体字中国語・繁体字中国語・日本語です。
  • 処理はMac上で行い、ネットワークには接続せず、データも収集しません。アクセシビリティと画面収録の権限が必要です。

ソースコードはGitHubで公開しています。ライセンスはPolyForm Noncommercial 1.0.0で、「ソース公開（source-available）」であり、オープンソースではありません。

プライバシー：Mac上で処理するか、アップロードするか

画像をWebサイトにアップロードして文字を読み取るOCRサービスは、画像が外部のサーバーに送られます。画面に個人情報や社外秘が写っているときは注意が必要です。

Pourtypeは文字の認識をMac上で行い、ネットワーク接続をせず、データも収集しません。

Pourtype ならショートカットひとつで

Pourtype は、こうした場面のために作った Mac のメニューバーアプリです。⌘⇧V を押すと、クリップボードの文字を実際のキー入力として欄に入力します。⌘⇧C で範囲を囲めば、画面に見える文字をコピーできます。処理はすべて Mac の中で行い、データは収集しません。Mac App Store で US$2.99 の買い切りです。

Pourtype は現在 App Store の審査中で、まだ販売していません。

よくある質問

日本語の文字も認識できる？

Pourtypeは、簡体字中国語・繁体字中国語・英語・日本語を認識します。macOSのテキスト認識表示は、Appleが地域や言語によっては利用できないと案内しているため、ご自身の画像で試してください。

画面の内容はアップロードされる？

Pourtypeは文字の認識をMac上で行い、ネットワーク接続をしません。外部へアップロードすることはありません。

履歴はどこに保存される？

取り込んだ文字と入力した文字の履歴は、Mac内に保存されます。検索でき、消去もできます。

ショートカットキーは変えられる？

変えられます。Pourtypeの設定で変更できます。初期値は⌘⇧Cです。

コピーした文字が貼り付けできない欄に入れたいときは？

貼り付けを止める入力欄には、Pourtypeの⌘⇧Vでクリップボードの内容をキー入力として打ち込めます。詳しくは貼り付け禁止のガイドをご覧ください。
