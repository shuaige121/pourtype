三件事

⌘⇧V

键入剪贴板

有些网站和对话框不让你粘贴。照常复制文字，点进输入框，按下快捷键，Pourtype 会替你一个键一个键地敲进去。换行以 Shift+Return 输入，聊天框不会提前发送。

⌘⇧C

抓取文字

在屏幕上任意位置拖一个框，哪怕文字在图片里。Pourtype 用 Apple 的 Vision 在本机识别并复制。支持简体中文、繁体中文、英文和日文。

历史记录

随时找回

抓取过和键入过的内容，都保存在你 Mac 上一份可搜索的列表里。可以再次复制，或再次键入。随时清除，也可以选择保留 7、30、90 或 365 天。

键入时，一切由你掌控

  • 屏幕会盖上一层磨砂遮罩，只留出正在输入的窗口。键盘和鼠标被锁定，焦点不会被移走。
  • 按 Esc 立即停止。如果有其他 App 切到前台，键入也会停止；按键只会送给目标 App。
  • 按住 ↑ 或 ↓ 调整速度，范围是每秒 3 到 150 个字符；按住 ← 或 → 调整节奏，从匀速到随机。
  • 一张卡片会显示目标 App 和窗口、正在流出的文字、进度和剩余秒数。有多个显示器时，其他显示器会出现一张小卡片，指向目标显示器。

怎么用

键入剪贴板

  1. 照常复制文字。
  2. 点进禁止粘贴的输入框，按 ⌘⇧V。
  3. 看着卡片就行，想停就按 Esc。

抓取文字

  1. 按 ⌘⇧C。
  2. 在文字上拖一个框，文字就复制到剪贴板了。

常见问题

Mac 上输入框禁止粘贴，怎么把文字输进去？

复制文字，点进输入框，按 Command-Shift-V。Pourtype 会把剪贴板文字当作真实按键敲进去，所以粘贴被拦住的地方也能用。键入时，屏幕会盖上磨砂遮罩，只留出正在输入的窗口，按 Esc 立即停止。

Mac 上怎么复制图片里的文字？

按 Command-Shift-C，在文字上拖一个框。Pourtype 用 Apple 的 Vision 在本机识别文字，并复制到剪贴板。支持简体中文、繁体中文、英文和日文。

安全吗？会把我的数据发到哪里吗？

Pourtype 在本机运行，不发起任何网络请求，也不收集任何数据。文字识别在你的 Mac 上完成，历史记录只保存在你的 Mac 上，随时可以清除。源码公开在 GitHub 上。

键入过程中怎么停下来？

按 Esc。键入立即停止，键盘和鼠标随即释放。如果有其他 App 切到前台，它也会自动停止。在密码框里，请按 Control-Option-Command-句号。

支持中文、日文和韩文吗？

支持。Pourtype 可以键入中文、日文、韩文和表情符号。从屏幕抓取文字时，可识别简体中文、繁体中文、英文和日文。

能在密码框里键入吗？

可以，但有一个限制。在密码框里 macOS 会开启 Secure Input，键盘无法被锁定，Pourtype 会退回为普通键入。按 Control-Option-Command-句号可以停止。

可以调整键入速度吗？

可以。按住 ↑ 或 ↓ 调整速度，范围是每秒 3 到 150 个字符；按住 ← 或 → 调整节奏，从匀速到随机。

可以更改快捷键吗？

可以。在设置里点一下快捷键，再按下新的组合，需要带 Command、Control 或 Option 中的一个。默认是 Command-Shift-V 打出剪贴板，Command-Shift-C 截图识字。

App 有哪些语言？

界面有简体中文、繁体中文、英文和日文，跟随 Mac 的系统语言。

多少钱？在哪里获取？

Pourtype 计划在 Mac App Store 上架，价格 2.99 美元，一次性买断，目前尚未上架。需要 macOS 14 或更高版本。源码在 GitHub 上，采用 PolyForm Noncommercial 1.0.0 许可：源码公开，个人和非商业使用免费，但不是开源软件。

天生私密

Pourtype 在本机运行，不发起任何网络请求，也不收集任何数据。

它需要辅助功能权限（用于键入，以及在键入时锁定键盘和鼠标）和屏幕录制权限（用于识别你框选区域内的文字）。只有在键入时才会锁定你的输入。
